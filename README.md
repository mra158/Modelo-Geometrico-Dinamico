# Modelo-Geometrico-Dinamico (MGD)
Posicionamiento basado en geometría articulada y dinámica de péndulos.

Objetivo: Desarrollar y evaluar un método de posicionamiento robótico que combine restricciones geométricas, modelos dinámicos simplificados y realimentación sensorial para reducir la complejidad computacional del cálculo de configuraciones articulares y mejorar la precisión del movimiento.
